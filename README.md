# MOJIMO V2.2i

Play: https://aosugoi.github.io/mojimo-v2/

A mobile-friendly Japanese vocabulary game with English, Japanese, and Bahasa Indonesia interfaces. The standalone index.html contains the game, artwork and sounds; no installation or build is needed.

## New features

- 19 pixel-art Mojimo with blinking, ear/tail motion, awake/rest poses, and ten travel backgrounds.
- Updated round Usamochi and Sarumaru C; the black cat is now Nekorin.
- Dream Keys story: wake lost friends from magical dream bubbles. Six starters are unlocked. A spin has a 10% chance to add a saved Dream Key; otherwise dream dust. Spend one key to wake one of twelve uncollected friends, with no duplicates. The persistent coin/key bar stays visible on every screen. First spin costs 1 coin, increasing by 1 after each spin.
- Secret pink leopard Goromaru unlocks only after collecting all eighteen other friends. His supplied spoken-name recording is cleaned and volume-balanced. All 19 characters say their own name using the supplied recordings. Clips have gentle noise cleanup, vocal EQ, de-essing, compression, character-specific pitch effects, subtle room reflections and a quiet sparkle-bell tail. Loudness and true peaks are measured, and clips play individually without overlap.
- Endless awards 20 coins for each completed level of ten correct answers. Failed/incomplete levels earn zero; rewards from completed levels remain.
- 60-second mode continues after mistakes and awards 2 coins per correct answer, capped at 100, only when the timer finishes. Early exit gives no timed reward.
- A gentle chime celebrates completed levels.
- Kana Garden teaches both 46-character basic alphabets, voiced sounds, contracted sounds, small kana and extended forms. Kana practice awards no coins.
- Fourteen guided lessons explain and cover all 114 vocabulary words/phrases used in the game, plus Study Hall and Last Run review. Study Hall memory checks award 1 coin, doubled from the second consecutive correct check.

Progress is stored in this browser and does not sync across devices or website addresses. All coins are earned in play; there are no purchases.
